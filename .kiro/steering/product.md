# Product Overview

DashCamApp is an Android application that provides dashcam functionality using the device's camera. The app allows users to record video continuously, manage recorded videos through a gallery interface, and configure recording settings.

## Core Features

- Video recording using device camera with CameraX API
- Gallery view for browsing and managing recorded videos
- Settings interface for configuring recording parameters
- Permission handling for camera, audio, and storage access
- Storage management for video files

## Target Platform

- Android devices with API 29+ (Android 10 and above)
- Requires camera hardware support
